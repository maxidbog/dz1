Консольное приложение формирует отчет по заказам клиентов из файла `orders_log.csv`.

## Запуск

Для вывода в консоль:

```
dotnet run --project ConsoleApp1/OrderReporter/OrderReporter.csproj -- console
```

Для сохранения отчета в файл:

```
dotnet run --project ConsoleApp1/OrderReporter/OrderReporter.csproj -- file
```

Стандартный параметр - `console`.

## Ввод

После запуска приложение запрашивает идентификаторы клиентов через пробел:

```
1010 1020
```

Некорректные идентификаторы выводятся как ошибки и пропускаются.

## Формат отчета

Каждая строка содержит разделенные табуляцией значения:

```
client_id   orders_sum  favorite_item_name
```

Если клиент не найден в файле, приложение выбрасывает исключение `ClientNotFoundException`.

Файлы отчетов создаются в каталоге `reports` рядом с исполняемым приложением.
